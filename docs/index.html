Fig. 03 / Spec sheet

How it runs.
By itself.

No one copies, pastes or publishes anything. A scheduled GitHub Actions run does all seven steps.

Step 01

Fetch

Twice a day the workflow reads the newsletter's public archive. It re-checks the last 10 days, so a post that failed once is picked up later.

Step 02

Clean

Tracking links, ads and footers are stripped. Only the teaching content is kept.

Step 03

Rewrite

Gemini turns the issue into a chapter: TL;DR, sections, code, key takeaways and interview questions. If the model is down, a plain summary is used instead.

Step 04

Sort

Each chapter gets a topic from its title and text, and a number from its date.

Step 05

Draw

A one-page infographic is rendered for every chapter, ready to share.

Step 06

Build

Static pages are written: this roadmap, one page per chapter and the full e-book.

Step 07

Ship

The new pages and the database are committed, and GitHub Pages redeploys the site.
